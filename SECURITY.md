# Security

Do not report a vulnerability through a public issue, discussion or pull request.

Use GitHub Private Vulnerability Reporting on the affected repository where it is available. Otherwise email security@chl.org.au with a brief description and a way to reach you; do not send exploit detail until a secure channel has been agreed. Use the same address for any CHL system that is not on GitHub.

Include the affected repository or system, steps to reproduce and the impact. CHL will acknowledge the report, triage it and coordinate any disclosure with you.

CHL does not run a bug bounty programme and does not pay for reports.
