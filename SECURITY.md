# Security

This is the default security policy for Community Housing Limited (CHL) repositories. If a repository publishes its own security reporting instructions, follow those first.

## Reporting a vulnerability

Do not report a security vulnerability through a public GitHub issue, discussion or pull request.

Where it is available on the affected repository, use GitHub Private Vulnerability Reporting. Open the repository on GitHub, select the Security tab, then select "Report a vulnerability". If the repository does not offer Private Vulnerability Reporting, email security@chl.org.au with a short description of the issue and how to reach you. CHL will reply with a secure channel; do not send technical or exploit detail until that channel has been agreed.

## What to include

A useful report states:

- the affected repository, system or service;
- steps to reproduce the issue;
- the impact you believe the issue has; and
- whether any data was accessed, and if so, what kind.

Include enough detail for CHL to reproduce the issue. Do not include more than is needed to demonstrate it.

## What to expect

CHL will acknowledge your report, triage it and decide what action is needed.

CHL will coordinate any public disclosure with you. Please do not disclose the issue to others until CHL has confirmed that it is resolved or has otherwise agreed to disclosure.

## Scope

This policy covers the repositories under https://github.com/CommunityHousingLimited.

Security concerns about CHL's websites, customer systems or other services that are not published on GitHub should be emailed to security@chl.org.au.

## Sensitive information

Do not include passwords, tokens, private keys, customer information, personal information, production data or other sensitive material in issues, pull requests, logs or screenshots.

## Safe harbour

CHL will not pursue researchers who act in good faith, follow this policy, avoid privacy violations and do not access or alter customer data beyond what is needed to demonstrate the issue.
