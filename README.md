# Community Housing Limited — GitHub defaults

This public `.github` repository provides CHL's public organisation profile and organisation-wide GitHub community-health defaults.

Repository-specific files take precedence where a repository needs different instructions or templates.

## Included

- Public organisation profile (`profile/`)
- Contribution guidance (`CONTRIBUTING.md`)
- Code of conduct (`CODE_OF_CONDUCT.md`)
- Security reporting guidance (`SECURITY.md`)
- Support guidance (`SUPPORT.md`)
- Pull request template (`PULL_REQUEST_TEMPLATE.md`)
- Issue forms (`.github/ISSUE_TEMPLATE/`)
- Organisation workflow template (`workflow-templates/`)
- Validation workflow for this repository (`.github/workflows/`)

The member-only organisation profile is maintained separately in the private `.github-private` repository.
